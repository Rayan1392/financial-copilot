تحلیل یک صندوق

ترکیب دارایی، بزرگ‌ترین سهم‌ها، خرید و فروش، ورود و خروج، چرخش صنعت، نقدینگی، ریسک، منابع سود و کیفیت NAV.

تحلیل یک نماد

تعداد صندوق‌های دارنده، خریدار، فروشنده، ورود جدید، خروج کامل، روند انباشت و کیفیت صندوق‌های مشارکت‌کننده.

تحلیل کل بازار

نمادهای دارای بیشترین اجماع خرید یا فروش، صنایع در حال جذب سرمایه صندوق‌ها و تغییر رفتار Risk-on/Risk-off.

اصل معماری: هیچ عدد مالی توسط LLM محاسبه نمی‌شود. تمام محاسبات در سرویس‌های قطعی و نسخه‌بندی‌شده انجام می‌شود؛ هوش مصنوعی فقط Intent را تشخیص می‌دهد، Read Model مناسب را فراخوانی می‌کند و پاسخ مستند فارسی تولید می‌کند.

100

پایه دامنه و Ingestion امن Workbook

مرجع هویت صندوق، گزارش، فایل خام، شیت‌ها، Revision و Evidence.

ورودی

فایل `.xlsx` ماهانه، Provider، نام فایل، Actor و متادیتای منبع.

پردازش

اعتبارسنجی امنیتی، SHA-256، ذخیره فایل خام، طبقه‌بندی شیت، استخراج دوره و ثبت Issue.

خروجی

یک `FundPortfolioWorkbookEnvelope` نسخه‌بندی‌شده که نرمالایزرهای بعدی بدون بازکردن Excel مصرف می‌کنند.

قواعد کلیدی Feature 100
  • خطاهای `#NAME?`، `#REF!`، `#N/A` و مشابه هرگز صفر تلقی نمی‌شوند.
  • Excel/LibreOffice و Recalculation در Runtime لازم نیست.
  • شیت ناشناخته حذف نمی‌شود و با وضعیت `Unclassified` نگهداری می‌شود.
  • فایل اصلاح‌شده همان دوره، Revision جدید می‌سازد و Revision قبلی Immutable باقی می‌ماند.
  • Statusهای اصلی: Queued، Parsing، PartiallyParsed، Parsed، NeedsReview، Failed و Superseded.

کنترل‌های کیفیت، امنیت و Trustworthiness

Data Quality

  • نگهداری RawValue و NormalizedValue به‌صورت جدا.
  • Evidence شامل Workbook، Sheet، Row/Cell، HeaderPath و ParserVersion.
  • Reconciliation بین مانده ابتدا، خرید، فروش و مانده پایان.
  • Reconciliation بین Detail Sheet و Summary Sheet.
  • نمایش Coverage و Unknown bucket به‌جای حذف داده حل‌نشده.

Security

  • عدم اجرای Macro، Formula، External Link یا Embedded Object.
  • محدودیت حجم، نسبت فشرده‌سازی، تعداد شیت/ردیف/ستون و طول سلول.
  • Raw Workbook و Source Row فقط برای Actor مجاز.
  • عدم ثبت محتویات حساس کامل در Log.
  • Actor/Tenant Isolation در UI، Tracker و Notification.

Analytical Integrity

  • CalculationVersion و MethodologyVersion روی تمام Snapshotها.
  • تفکیک Base Consensus از Quality-weighted Consensus.
  • حداقل Sample برای Feature 107؛ در غیر این صورت `Unavailable`.
  • عدم عبور Streak از دوره گزارش‌نشده یا Rejected بدون Policy.
  • عدم ادعای Real-time Flow از گزارش ماهانه.

AI & Compliance

  • LLM مجاز به ساخت عدد، SQL یا رتبه‌بندی جدید نیست.
  • همه پاسخ‌ها شامل دوره گزارش، Freshness، Citation و Warning هستند.
  • هیچ خروجی با عبارت توصیه خرید یا فروش ارائه نمی‌شود.
  • اعلان‌ها تاخیر ماهانه داده را صریح بیان می‌کنند.
  • اصلاح گزارش، Event قبلی را بازنویسی نمی‌کند؛ رابطه Correction/Supersession ثبت می‌شود.
